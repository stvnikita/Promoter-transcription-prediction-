Репозиторий включает блокноты с кодом для обучения использованных в работе моделей

## 🧬 Модели и подходы

### 1. Трансформерные модели (BERT)
- **DNA-BERT**: Модель, предобученная на полном геноме арабидопсиса
- **CREBERT**: Модель, предобученная на цис-регуляторных элементах
- **Анализ эмбеддингов**: Визуализация с помощью UMAP
- **Transfer Learning**: Дообучение для задач регрессии и классификации

### 2. Классическое машинное обучение
- **CatBoost**: Градиентный бустинг с расчетными признаками:
  - GC-состав
  - Энтропия последовательностей
  - Длина и количество цис-регуляторных элементов
  - Количество CpG островков

### 3. Сверточные нейронные сети
- **CNN**: Архитектура с one-hot encoding последовательностей ДНК

## 📊 Основные результаты

### DNA-BERT
- ❌ Эмбеддинги не показывают кластеризацию по целевой переменной
- ❌ Низкое качество предсказаний в задаче регрессии (R² ≈ 0.1)
- ⚠️ Несмотря на потенциал, модель не справилась с данной задачей

### CREBERT
- ✅ Хорошие результаты на этапе предобучения
- ❌ Неудача в задачах регрессии и классификации после дообучения
- ❌ Эмбеддинги не содержат разделимых паттернов

### CatBoost
- ❌ Низкое итоговое качество предсказаний
- ⚠️ Расчетные признаки недостаточны для точного прогноза

### CNN
- ❌ Низкая эффективность, несмотря на ожидания

## 📊 Общий вывод:
Использованные признаки недостаточны для точного прогноза в задаче предсказания уровня транскрпиции в растительном организме
